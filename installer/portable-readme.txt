CPAQuota 便携版

解压到可写文件夹后，直接双击 CPAQuota.exe。
保留同目录的 portable.flag 和 CPAQuota.exe.config。程序会把配置保存在同目录 data 文件夹。
右键任务栏面板或托盘图标可打开设置或退出，无需 CMD 脚本。
Windows 11 使用托盘左侧的兼容面板；托盘图标可能收纳在“显示隐藏的图标”中。
更新旧版时先退出程序，再替换 CPAQuota.exe 和 CPAQuota.exe.config，保留自己的 data 文件夹。
需要 Windows 与 .NET Framework 4.8。

首次启动填写自己的 CPA 服务地址和管理密钥。CPAMP 历史统计为可选功能。
本包未预置服务地址、账号或密钥。
转交便携文件夹给他人时，请先删除自己的 data 和 logs 文件夹。

项目主页：https://github.com/songxff/CPAQuota
