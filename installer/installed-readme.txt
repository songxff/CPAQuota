CPAQuota 安装版

从开始菜单启动 CPAQuota。右键任务栏面板或托盘图标可打开设置或退出。
Windows 11 使用托盘左侧的兼容面板；托盘图标可能收纳在“显示隐藏的图标”中。
配置保存在当前用户的 %LOCALAPPDATA%\CPAQuota\data，
程序文件安装在所选安装目录。卸载时保留用户配置。
可通过 Windows 应用列表或开始菜单中的卸载入口卸载。

需要 Windows 与 .NET Framework 4.8。
首次启动填写自己的 CPA 服务地址和管理密钥，CPAMP 历史统计为可选功能。
本包未预置服务地址、账号或密钥。

项目主页：https://github.com/songxff/CPAQuota
